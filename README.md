# 나의 할 일 목록

간단한 순수 HTML/CSS/JavaScript로 만든 할 일 목록(Todo List) 앱입니다. 별도의 빌드 도구나 프레임워크 없이 동작합니다.

## 주요 기능

- 할 일 추가
- 전체 / 진행중 / 완료 필터링
- 완료 개수 표시
- 완료된 항목 일괄 삭제

## 실행 방법

빌드 과정이 필요 없습니다. `index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

## 파일 구성

- `index.html` — 페이지 구조
- `style.css` — 스타일
- `main.js` — 동작 로직
